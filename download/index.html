Download Consort

Apps for your desktop and phone. Consort also works in any modern browser: just open your organization’s address.

Desktop

  • Windows 64-bit installer, from GitHub Coming soon
  • Linux 64-bit .tar.xz archive, from GitHub Coming soon
  • Microsoft Store Windows Coming soon
  • macOS Apple silicon and Intel Coming soon

On Windows, download Consort-Setup-<version>-x64.exe. It installs for your account without administrator rights. The installer isn’t code-signed yet, so Windows will warn you before it runs; here’s how to check the file and continue.

On Linux, download Consort-<version>-x64.tar.xz, unpack it, and run sudo sh install.sh from inside.

Mobile

  • F-Droid Android, without Google services Coming soon
  • Google Play Android Coming soon
  • App Store iPhone and iPad Coming soon
  • Android APK Direct download, from GitHub Coming soon

The F-Droid version contains no Google or Firebase code, and delivers notifications through UnifiedPush. The mobile app privacy policy explains the difference, and Push notifications covers every way to get them.

Server

Consort needs a server to connect to. Run your own with one command.
